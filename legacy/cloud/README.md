# Déploiements cloud historiques

Ces fichiers Fly.io, Render et Hugging Face correspondent à une ancienne version légère du studio.
Ils n'incluent pas Blender, l'orchestrateur quotidien ni les garanties de persistance actuelles et ne
doivent pas servir au déploiement de production.

Le déploiement supporté est `docker-compose.yml` sur une machine Linux persistante. Voir
[`docs/AUTOMATION.md`](../../docs/AUTOMATION.md).
