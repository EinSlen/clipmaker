AUTOMATISATION

Un compte, un jeu

Connexion requise

Choisis le jeu, l’obstacle, l’heure et les destinations de chaque compte. Cloudflare respecte le créneau choisi et GitHub fournit le second départ de sécurité.

Sessions non vérifiées
Connecte-toi avec GitHub pour charger les comptes et les jeux.

Jeu ou obstacle modifié ? Sauvegarde, puis lance « Générer maintenant » pour préparer la vidéo du jour. Si un envoi a déjà commencé, termine d’abord avec le même jeu ; le nouveau choix servira le lendemain. Une ancienne vidéo ne remplace jamais automatiquement le jeu choisi.

Créer puis connecter un nouveau compte1. Crée le compte sur TikTok ou Google. 2. Ouvre le navigateur privé ClipMaker dans le Codespace. 3. Connecte-toi puis utilise « Synchroniser avec le cloud » dans le Studio.
Créer TikTok ↗ Créer Google ↗ Connecter dans Codespace ↗ Studio local (si démarré)

VOIX D’EDITS · EN ANGLAIS

Des voix parlées, pas des chansons

Connexion requise

Monologues tristes ou revenge : voix au premier plan, émotions et pauses conservées. Les extraits tournent par compte, sans répétition avant la fin d’un cycle si la bibliothèque reste inchangée. Le choix du jour reste fixé pour les relances.

Connecte-toi pour gérer les voix privées.
+ Importer un extrait d’edit

Importe un fichier que tu peux réutiliser sur TikTok et YouTube. Une playlist ou un lien TikTok ne prouve pas ces droits. La source reste sur ton ordinateur : seul l’extrait choisi est envoyé au cloud. Aucun prélèvement automatique de dialogues de films.

Ensuite, choisis « Voix d’edit — triste / revenge / mix » dans ton compte et sauvegarde le planning. Aucun mode n’est activé à ta place. Une bibliothèque vide bloque ce mode avant le calcul Blender.
